模块以多个独立 TS 文件作为 SST 应用入口，每个文件负责一个子系统：`app.ts` 定义 API Worker、Astro 文档站和静态 WebApp；`console.ts` 编排 Planetscale 数据库分支/密码、Auth Worker、Stripe 产品/价格/Coupon、SolidStart Console 应用及日志处理 Worker；`lake.ts` 构建 AWS S3 Tables + Glue Catalog + Firehose Iceberg 数据湖，并通过 SST Service 暴露 ingest 服务；`stats.ts` 复用 lake 能力创建 inference event 表、Stats 数据库与同步任务；`monitoring.ts` 通过 honeycombio provider 注册查询与 Trigger 告警；`enterprise.ts` 部署企业版 SolidStart 应用；`stage.ts` 集中计算域名、ZoneID 与阶段开关；`secret.ts` 统一管理 Secret 与随机密码并以 `sst.Linkable.wrap` 暴露 value。依赖方向单向：各子系统仅依赖 `stage.ts`、`secret.ts` 以及彼此导出的 `sst.Linkable`，不反向引用，形成清晰的边界。
