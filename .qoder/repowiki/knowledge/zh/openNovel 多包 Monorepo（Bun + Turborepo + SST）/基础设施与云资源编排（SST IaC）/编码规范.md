- 所有敏感凭据通过 `new sst.Secret("NAME")` 或 `random.RandomPassword` 声明，并统一从 `./secret.ts` 的 `SECRET` 对象导出，避免硬编码。
- 跨子系统共享的资源通过 `new sst.Linkable("Name", { properties })` 暴露属性，由消费方通过 `link: [...]` 注入，而非直接传递对象。
- 阶段差异化逻辑集中在 `stage.ts` 中通过 `$app.stage` 判断，其他模块仅导入结果（domain、deployAws、shortDomain），不在自身内重复分支判断。
- Cloudflare Worker 使用 `sst.cloudflare.Worker` 声明 handler 路径指向 `packages/*/function/src/*.ts`，并通过 `link` 数组绑定依赖资源。
- AWS 资源命名统一采用 `opencode-${$app.stage}-*` 前缀模式，非生产环境启用 `forceDestroy: true` 以便销毁重建。
- 监控查询使用 `calculatedField` 辅助函数对表达式做哈希后缀，避免 Honeycomb 因字段名不变导致的缓存问题。
