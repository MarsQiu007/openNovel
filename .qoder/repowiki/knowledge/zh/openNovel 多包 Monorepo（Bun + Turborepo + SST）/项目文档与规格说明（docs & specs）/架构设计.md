本模块为纯文档/规格目录，不含可执行代码，按用途分为两层：
- `docs/`：面向用户与开发者的设计说明与截图，如 `cascade-consistency-design.md` 描述级联一致性（entity_refs + pending_updates + saga 统改）的整体方案，`screenshots/` 保存 UI 截图。
- `specs/`：面向实现的规格文档，按主题分目录组织：`v2/` 定义核心服务、插件钩子、配置 schema、provider 模型与策略、会话、工具等 v2 重构规范；`storage/` 记录 Effect Drizzle SQLite 适配包与数据库迁移决策；根级的 `project.md` 定义多项目/多 session API 契约，`tui-package.md` 详细规定 `@opencode-ai/tui` 包拆分的 10 个阶段、所有权边界与验证门禁。
所有文档以 Markdown 为主，辅以 HTML 接口文档（`v2/api.html`），通过文件命名与目录结构体现领域划分，无运行时依赖方向。
