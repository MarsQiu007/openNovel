单包 Remotion 应用，入口 `src/index.tsx` 通过 `registerRoot` 注册一个 Root 组件，内部用 `<Composition>` 声明所有片段（GLM52Rise、NZSheep、NovelTokens、FlashShare、MiniMaxClimb、JuneTotals），每个片段对应一个独立的 `.tsx` 文件（`video.tsx`、`sheep.tsx`、`novel.tsx`、`flash.tsx`、`minimax.tsx`、`june.tsx`），导出同名 React 函数组件。
- 数据层：`data.ts` 集中存放经过验证的每日 token 统计数据（`days`、`segments`、`launchIndex`、`glmWeekTokensT`），被 `video.tsx` 消费。
- 资源层：`public/` 下的 `book.jpg`、`sheep.jpg` 通过 `staticFile()` 在 Remotion 中引用。
- 输出层：`out/` 目录由 `remotion render` 命令写入生成的 MP4/PNG 文件。
- 依赖方向单向：各片段组件 → `data.ts` / `public/*`，无跨片段互相导入。
