- 每个视频片段是一个独立文件，导出与 Composition id 同名的 React 函数组件，并在 `index.tsx` 中以 `<Composition id="..." component={...} />` 形式注册。
- 动画通过 Remotion 的 `useCurrentFrame()` + `interpolate(frame, [...], [...], { extrapolateLeft/right: 'clamp', easing })` 模式驱动，配合 `Easing.inOut(Easing.cubic)` 等缓动函数。
- 视觉样式集中在模块级常量对象 `c`（颜色）和 `MONO`（字体族）中，所有组件复用同一套设计令牌。
- DATA wordmark 以内联 SVG 组件 `DataWordmark` 形式在每个文件中重复定义，保持品牌标识一致。
- 数值展示统一使用 `Intl.NumberFormat('en-US')` 进行格式化，大整数使用下划线分隔符书写（如 `40_915_594_381`）。
- 背景图通过 `Img src={staticFile('*.jpg')}` 引用 `public/` 资源，并配合 CSS `objectFit: 'cover'` 与渐变遮罩保证文字可读性。
