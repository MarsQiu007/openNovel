- 所有 GitHub 环境变量通过统一的 useEnv* 函数集中读取与校验（如 useEnvModel、useEnvShare、useEnvAgent），失败时抛出明确错误消息。
- 对 GitHub 事件的上下文统一通过 useContext() 包装，支持 MOCK_EVENT/MOCK_TOKEN 切换至 mock 模式以便本地调试。
- 异步操作失败时统一在 try/catch 中捕获，将错误信息写入 comment 并通过 core.setFailed 标记 Action 失败。
- Git 操作通过 bun 的 `$` shell 语法执行，并在 finally 块中恢复 Git 配置以清理运行时修改。
- 对外部服务调用（如 OpenCode server、GitHub API）采用重试或轮询机制（如 assertOpencodeConnected 最多重试 30 次）。
