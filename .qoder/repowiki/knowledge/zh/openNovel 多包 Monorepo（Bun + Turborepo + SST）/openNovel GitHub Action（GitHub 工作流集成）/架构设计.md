该模块由两部分组成：
- `github/` 目录是实际的 GitHub Action 包，入口为 `index.ts`，通过 `action.yml` 声明为 composite action（`runs.using: "composite"`），在 runner 上安装 opennovel CLI 后执行 `opennovel github run`。
- `index.ts` 采用单文件主程序架构：启动本地 opencode server（端口 4096），通过 `@actions/github` 获取事件上下文，使用 `@octokit/rest` 和 `@octokit/graphql` 访问 GitHub API，通过 `@opencode-ai/sdk` 与 OpenCode 服务端交互；根据事件类型分支处理 issue_comment 和 pull_request_review_comment，区分本地 PR、fork PR 和纯 issue 三种场景，分别执行 checkout、chat、commit、push、create PR 等流程。
- 认证流程支持两种模式：默认通过 OIDC 向 `api.opencode.ai/exchange_github_app_token` 交换 token，或通过 `use_github_token` 环境变量直接使用 GITHUB_TOKEN。
- `.github/` 目录包含仓库级模板（CODEOWNERS、TEAM_MEMBERS、pull_request_template.md、ISSUE_TEMPLATE、actions、workflows），作为仓库治理与协作规范，不直接参与 Action 运行逻辑。
- 依赖方向单向向外：index.ts → @actions/* + @octokit/* + @opencode-ai/sdk + bun/$ shell 工具，无内部子模块拆分。
