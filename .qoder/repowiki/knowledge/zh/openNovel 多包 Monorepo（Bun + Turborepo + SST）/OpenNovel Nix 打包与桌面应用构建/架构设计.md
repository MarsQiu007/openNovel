本模块由三个 Nix Derivation 文件与两个 Bun 辅助脚本组成：
- `node_modules.nix`：通过 `bun install --frozen-lockfile` 安装并缓存 `packages/opencode`、`packages/desktop`、`packages/app` 的 node_modules，使用 `hashes.json` 中按 hostPlatform.system 区分的 sha256 哈希实现不可变缓存；构建后调用 `scripts/canonicalize-node-modules.ts` 重建 `.bun/node_modules` 符号链接，再调用 `scripts/normalize-bun-binaries.ts` 生成 `.bin` 入口。
- `opencode.nix`：复用 `node_modules` 输出，在 `packages/opencode` 下执行 `bun script/build.ts --single --skip-install` 与 `schema.ts` 生成 schema，最终产出 `$out/bin/opennovel` 并通过 `wrapProgram` 注入 ripgrep 等运行时依赖。
- `desktop.nix`：依赖 `opennovel` 包，使用 electron_41 + electron-builder 构建桌面应用；Linux 侧通过 autoPatchelfHook 修复 ELF 依赖、复制图标与 metainfo，Darwin 侧通过 darwin.autoSignDarwinBinariesHook 签名 .app 包。
- 两脚本均基于 Bun 的 fs/promises API 操作 `.bun` 目录，分别解决 bun 缓存布局差异与二进制入口规范化问题。
- 依赖方向单向：`desktop.nix` → `opencode.nix` → `node_modules.nix`，`hashes.json` 作为外部输入被 `node_modules.nix` 读取。
