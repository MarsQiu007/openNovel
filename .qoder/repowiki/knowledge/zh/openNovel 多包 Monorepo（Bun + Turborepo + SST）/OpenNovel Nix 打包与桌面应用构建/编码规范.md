- 所有 Derivation 使用 stdenvNoCC.mkDerivation 并以 `{ lib, stdenvNoCC, ... }` 形式声明参数，便于跨平台复用。
- 平台相关逻辑通过 `lib.optionalString stdenv.hostPlatform.isLinux / isDarwin` 条件分支组织，避免硬编码平台判断。
- 构建前统一通过 `substituteInPlace` 将 Bun 版本检查从 `throw new Error` 降级为 `console.warn`，以兼容不同 Bun 版本。
- node_modules 构建阶段先 `cp -R ${node_modules}/. .` 再对 `node_modules` 与 `packages/*/node_modules` 执行 `patchShebangs`。
- 环境变量集中通过 `env = ... // { ... }` 合并方式注入，如 `OPENCODE_DISABLE_MODELS_FETCH`、`ELECTRON_SKIP_BINARY_DOWNLOAD` 等。
