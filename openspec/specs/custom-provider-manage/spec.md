# custom-provider-manage Specification

## Purpose
自定义提供商（OpenAI 兼容端点）的完整生命周期管理：创建后可再编辑、可删除，且能为每个模型配置上下文长度、推理能力、成本等细节参数，使用户无需手工改全局配置文件即可维护自定义接入。

## Requirements

### Requirement: 已创建的自定义提供商可再次编辑

用户打开设置中心已存在的自定义提供商进行编辑时，系统 SHALL 以该提供商当前已持久化的配置预填表单，提供商 ID 字段 SHALL 锁定不可修改，API key 字段留空 SHALL 表示保留已存凭据（不回写、不清除）；编辑保存时 SHALL NOT 因「提供商 ID 已存在」拒绝保存。保存成功后该提供商 SHALL 不再处于禁用列表中，其连接信息与模型列表立即按新配置生效。

#### Scenario: 编辑预填并保存生效

- **WHEN** 用户在设置中心打开一个已创建的自定义提供商的编辑入口，修改 baseURL 或模型清单后保存
- **THEN** 表单以保存前配置预填（ID 字段不可编辑），保存不被重复 ID 校验拦截，重新打开编辑时看到新值，后续会话按新 baseURL/模型发起

#### Scenario: API key 留空保留原凭据

- **WHEN** 用户编辑某自定义提供商但不触碰 API key 字段（留空）直接保存
- **THEN** 已存凭据保持不变，该提供商已连接的会话继续可用

#### Scenario: 填入新 key 后旧 key 不再被使用

- **WHEN** 用户在编辑时填入新的 API key 并保存
- **THEN** 后续请求携带新 key，任何一侧凭据存储都不再提供旧 key

### Requirement: 自定义提供商可删除且清理干净

用户对自定义提供商执行删除（二次确认后）时，系统 SHALL 从全局配置中移除该提供商记录，并同步清理 `disabled_providers`/`enabled_providers` 中该提供商的残留条目与该提供商在旧版凭据存储与 Integration 凭据库中的凭据；删除后设置中心列表与可选提供商集合 SHALL 不再出现该提供商。删除操作 SHALL NOT 影响其他提供商与内置提供商的配置。

#### Scenario: 删除后提供商与凭据同时消失

- **WHEN** 用户确认删除一个已创建的自定义提供商
- **THEN** 该提供商从设置列表与可用提供商集合中消失，其凭据不再被任何一侧存储解析到，禁启用列表中无该 ID 残留

#### Scenario: 删除不影响其他配置

- **WHEN** 全局配置中存在多个自定义提供商与内置提供商配置，用户删除其中一个
- **THEN** 其余提供商记录、禁启用列表其他条目与全局配置其他字段保持不变

#### Scenario: 取消确认不执行删除

- **WHEN** 用户在删除确认中取消
- **THEN** 全局配置与凭据存储无任何变化

### Requirement: 自定义提供商的模型可配置细节参数

创建或编辑自定义提供商时，系统 SHALL 允许为每个模型配置以下细节参数并随提供商记录持久化：上下文长度（`limit.context`）、可选输入上限（`limit.input`）、输出上限（`limit.output`）、推理能力开关（`reasoning`）、逐段推理（`interleaved`）、采样开关（`temperature`）、工具调用开关（`tool_call`）、附件开关（`attachment`）、输入/输出成本（`cost.input`/`cost.output`）、模型状态（`status`）、模型家族（`family`）。留空的可选参数 SHALL NOT 写入配置（回落运行时缺省）。

#### Scenario: 设置上下文长度与推理能力后生效

- **WHEN** 用户为自定义提供商的某模型填入上下文长度 131072、开启推理能力并保存，随后在该模型发起会话并选择推理档位
- **THEN** 会话运行时使用该上下文长度进行窗口管理，且该模型呈现推理档位选择（由推理能力驱动）

#### Scenario: 留空细节参数回落缺省

- **WHEN** 用户新建自定义提供商，模型行未展开或未填写任何细节参数
- **THEN** 保存的配置不含这些键，运行时按既有缺省行为处理（与今天的创建路径一致）

#### Scenario: 编辑时细节参数回显

- **WHEN** 用户打开一个模型细节参数已持久化的自定义提供商进行编辑
- **THEN** 表单回显已存的上下文长度、推理开关等值，修改保存后再次打开为新值
