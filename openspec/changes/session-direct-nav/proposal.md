# Proposal

## Why

上一变更（subagent-session-binding）解决了「子代理会话能否进入」，但「进入过程」仍有体验断点：在工作台对话面板时间线点击子代理卡片等书内打开会话的动作，会先离开工作台路由、进入已退役的独立会话路由，由重定向宿主解析归属后再回跳。这一去一回导致工作台整体卸载、解析期间整屏无内容空白（实测空窗约 0.8–1 秒，深色主题下表现为「黑一下」），完成后工作台又整体重新挂载；外部深链入场同样存在整屏空白。

## What Changes

- 工作台内会话导航直连：时间线子代理卡片点击、卡片链接（复制/中键/新标签）、时间线内的会话引用链接、返回父会话入口，全部在同一工作台路由内完成（仅路由参数变化），不再经独立会话路由重定向；工作台不因导航重新加载，布局与面板状态不被重置。
- 会话链接携带书籍上下文：工作台的会话链接生成与导航补齐书籍归属（novelID），产出的链接地址为书内路由形态——复制或新标签打开一步到位；旧布局与外部深链的既有行为不变。
- 重定向宿主加载态：独立会话路由的重定向宿主在归属解析期间呈现跟随主题的加载状态，消除深链入场的整屏空白；解析完成后的入书与降级逻辑保持不变。
- 收敛与验证：全量核对旧式会话链接生成点并收敛工作台内残留；扩展 e2e 断言直连形态、无中间路由与加载状态。

## Non-Goals

- 不改会话归属解析（绑定行 → 父链最近绑定祖先 → 无归属）与降级规则；不新增数据迁移。
- 不删除独立会话路由与外部深链兜底——深链必须仍然可达，本变更只改善其呈现。
- 不改旧布局（newLayoutDesigns=false）的导航行为。
- 不引入页面过渡动画、骨架屏体系或路由结构重构；加载状态保持最简（不新增文案）。
- 不触碰 i18n locale 文件；无 Protocol / Server HttpApi 与数据模型改动，无需 SDK 再生成。

## Capabilities

### New Capabilities

（无——本变更细化既有能力的导航与呈现要求，不引入新的系统能力。）

### Modified Capabilities

- `novel-workspace-layout`：「绑定会话统一在工作台打开」新增书内直连条款与场景——工作台内触发的打开会话动作仅参数变化、不进入独立会话路由，链接兜底同址，返回父会话同此。
- `titlebar-tabs`：「会话归属书籍」新增重定向宿主呈现条款与场景——归属解析期间呈现跟随主题的加载状态，不呈现整屏空白。

## Impact

- **packages/app**（主要改动面）：会话链接提供层补齐书籍上下文；工作台布局接入；返回父会话入口直连；重定向宿主加载态；相关单测与 e2e 更新。
- **e2e**：更新 subagent-child-navigation spec 的链接与直达断言，新增重定向加载状态用例。
- **packages/novel-store / plugin / opennovel / desktop / schema / protocol / client**：无改动，无需重新 generate。
- **数据兼容性**：不触碰数据模型与存储，纯前端导航与呈现调整，对存量数据零影响。
- i18n locale 文件保持不动。
