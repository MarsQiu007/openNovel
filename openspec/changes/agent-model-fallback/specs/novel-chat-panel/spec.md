# Spec Delta

## ADDED Requirements

### Requirement: 会话创建入口钉住当前模型选择

对话面板的会话创建入口（无归属会话时的首条消息懒创建、切换器「+」新建轻会话）在创建会话时 SHALL 将当前模型选择（含推理档位）钉入新会话，其取值与输入控件栏显示的模型解析结果同源；当前无可用模型选择时 SHALL 不钉入，由服务端模型解析链决定。

#### Scenario: 懒创建首条消息钉住当前模型

- **WHEN** 用户在无归属会话的书籍对话面板提交首条消息，且当前模型选择为某 provider 的某模型
- **THEN** 系统创建会话时将该模型（含档位）钉入会话，首条消息以该模型执行

#### Scenario: 新建轻会话钉住当前模型

- **WHEN** 用户点击切换器「+」新建会话，且当前模型选择为某 provider 的某模型
- **THEN** 系统创建会话时将该模型（含档位）钉入会话

#### Scenario: 无可用模型选择时不钉入

- **WHEN** 用户提交首条消息或新建会话，且当前无任何可用模型选择
- **THEN** 创建会话不携带模型，按服务端模型解析链（代理配置 → 目录默认）执行
