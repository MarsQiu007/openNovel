# Spec Delta

## ADDED Requirements

### Requirement: 待处理尾部重规划

活动或挂起工作队列 SHALL 支持以一组新的非空单元原子替换当前全部待处理单元。已完成、进行中、跳过与受阻单元及其序号、笔记 MUST 保持不变；新单元依次成为待处理尾部。任一校验或写入失败时队列保持原样，挂起队列重规划 MUST NOT 自动恢复执行。

#### Scenario: 原子替换待处理尾部

- **WHEN** 调用方对活动队列提交新的待处理尾部且全部校验通过
- **THEN** 旧待处理单元被新单元替换，其他状态单元保持原序号与内容，队列继续按新尾部推进

#### Scenario: 历史单元不可被重写

- **WHEN** 队列已有完成、进行中、跳过或受阻单元并发生尾部重规划
- **THEN** 这些单元及其状态、序号和笔记不被删除、重置或修改

#### Scenario: 重规划失败回滚

- **WHEN** 新尾部为空、队列已终结或任一写入失败
- **THEN** 系统拒绝本次重规划，原队列全部单元与状态保持不变

#### Scenario: 挂起队列保持挂起

- **WHEN** 用户对挂起队列重规划待处理尾部
- **THEN** 新尾部持久化且队列仍为挂起，不合成续跑指令或唤醒会话
