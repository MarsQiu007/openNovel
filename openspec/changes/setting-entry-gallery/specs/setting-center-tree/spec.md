# Spec Delta

## Purpose

随设定图片画廊（setting-entry-gallery）为世界观条目与角色的显示标签组各新增「画廊」标签，原「图」标签的可视化语义保持不变。

## MODIFIED Requirements

### Requirement: 按节点类型声明的显示标签组

中央区 SHALL 按节点类型渲染显示标签组：世界观条目为「内容 / 编辑 / 画廊」；角色为「内容 / 编辑 / 图 / 画廊」；世界观板块节点为「列表 / 地图」；角色板块节点为「列表 / 关系图」；书籍信息、伏笔、写作风格、灵魂、技法库、整理等单页节点 SHALL NOT 渲染标签条。「图」标签 SHALL 渲染可视化视图（角色 ego 关系图、世界地图）；「画廊」标签 SHALL 渲染对应条目或角色的图片画廊（见 setting-entry-gallery）。

#### Scenario: 世界观条目两个标签

- **WHEN** 用户选中一个世界观条目
- **THEN** 中央区标签条显示「内容」「编辑」两项，默认落在「内容」阅读视图，并在两项之外提供「画廊」标签

#### Scenario: 角色三个标签且图为 ego 关系图

- **WHEN** 用户选中一个角色并切到「图」标签
- **THEN** 中央区渲染以该角色为中心节点的关系图，标签条在三项之外提供「画廊」标签

#### Scenario: 角色画廊标签

- **WHEN** 用户选中一个角色并切到「画廊」标签
- **THEN** 中央区渲染该角色的图片画廊，ego 关系图不因此变化

#### Scenario: 单页节点无标签条

- **WHEN** 用户选中「写作风格」节点
- **THEN** 中央区直接渲染风格表单，不渲染显示标签条
