# Spec Delta

## ADDED Requirements

### Requirement: 创建小说入口图形语义

书架页的「创建小说」入口 SHALL 显示创建语义的加号图形，SHALL NOT 因引用的图标名未注册而渲染为空白。当图标资产缺失时，系统 SHALL 沿用现有缺失兜底行为：渲染空白并在开发环境给出可发现告警。

#### Scenario: 打开书架创建入口

- **WHEN** 用户打开已配置书架目录的书架页
- **THEN** 「创建小说」按钮显示加号图形，且开发环境不出现该按钮的图标缺失告警

#### Scenario: 创建入口保持原有行为

- **WHEN** 用户点击「创建小说」
- **THEN** 系统仍进入新建小说向导，入口文案与导航目标不变
