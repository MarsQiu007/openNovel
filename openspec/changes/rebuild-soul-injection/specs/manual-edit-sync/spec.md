# Spec Delta

## ADDED Requirements

### Requirement: 手动编辑重建注入灵魂

手动编辑同步的章节正文重建 SHALL 与升级重建共用同一灵魂注入语义：小说灵魂优先、全局兜底、均空不注入、作为系统提示词传递、结构化输出约束不受影响。同一章节因手动编辑与升级触发的重建 SHALL 得到一致的灵魂注入，SHALL NOT 因任务来源不同而差异对待。

#### Scenario: 手动编辑重建携带灵魂

- **WHEN** 章节正文手动保存触发 observer 重建且该小说或全局存在非空灵魂
- **THEN** 重建模型调用携带按合并规则选择的灵魂作为系统提示词

#### Scenario: 来源无关的一致注入

- **WHEN** 同一章节分别因手动编辑与批量升级触发重建且灵魂设置未变
- **THEN** 两次重建的模型调用携带相同的灵魂系统提示词

#### Scenario: 无灵魂手动重建不变

- **WHEN** 章节正文手动保存触发重建且小说与全局灵魂均为空
- **THEN** 重建不携带灵魂系统提示词，同步结果与现状一致
