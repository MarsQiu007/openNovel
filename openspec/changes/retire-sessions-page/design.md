# Design

## Context

- `session-book-only`（已归档）已把会话收敛为「必须归属于书籍」：独立会话路由成为重定向宿主、自由会话入口下线、书内切换器支持子代理嵌套。该变更的 D2 明确把「会话列表页整页下线」挂起为后续首页重设计事项——本变更接续落地。
- 会话列表页左栏（`sessions-novel-sidebar.tsx` 的 `NovelSessionGroupList`）目前是以下动作的唯一 UI 触发点：主会话归档（含子代理级联与确认）、导出会话 JSON（调试用）。页面右栏为最近会话列表与搜索，搜索可从命令面板（Ctrl+K）部分补偿。
- 书内右栏对话面板与列表页无共享宿主：`workspace-frame.tsx` 直接渲染 `NovelSessionSwitcher` + `SessionPage`，不经过 `/sessions`；`openSessionRouted`、`SessionPage`、会话谱系（lineage）与自动回跳均与列表页解耦。

## Goals / Non-Goals

- Goals：会话列表页与标题栏入口彻底退役；列表页独有的会话管理动作迁移到书内右栏切换器；共享代码与 e2e 同步收敛；spec 与实现一致。
- Non-Goals：书内右栏既有能力不动（切换/新建/嵌套/空态/自动回跳）；不做跨书搜索替代；不清理遗留自由会话数据；不改 i18n 文件；不改性能基准。

## Decisions

### D1 整页下线，而非保留改造

页面常态已无独立能力：左栏与书内右栏同源（绑定会话），右栏为最近会话重排；唯二独有的归档/导出动作迁走后，页面只剩信息架构冗余。备选「保留页面但隐藏入口」仍留死代码与双宿主维护成本，弃。「改造成最近会话聚合页」属首页重设计范畴，非本变更目标，弃。

### D2 旧链接降级到书架，路由删除而非保留宿主

`/sessions` 路由删除渲染并降级重定向到书架（与既有「未绑定会话深链降级书架」同语义）。理由：书签/历史/外部链接仍可能命中该路径，直接 404 体验差；保留重定向宿主与既有 `SessionRedirect` 的「退役即降级」范例一致，且无数据依赖。实现只需一个 `Navigate` 组件，不保留页面代码。

### D3 归档/导出动作落点为书内切换器会话项的右键菜单

- 切换器会话项（主会话与子代理子项）右键打开 `ContextMenu`，提供「归档」与「导出会话（JSON）」两项；动作与样式复用 `sessions-novel-sidebar.tsx` 中已验证的菜单形态，保持一致。
- 归档走级联：目标存在未归档子代理时先弹确认（复用列表页确认弹窗的文案与计数形状），确认后级联归档主会话与全部未归档子代理；无子代时直接归档。归档的会话立即从切换器列表消失。
- 导出复用「拉取会话信息与全部消息、生成 JSON 文件下载」的既有实现（调试用途），行为与列表页一致。
- 当前打开的是被归档会话时，面板行为依赖既有自动回跳（最近未归档绑定会话或懒创建空态），不新增导航逻辑——回跳逻辑由 `novel-chat-panel` 既有 requirement 覆盖。
- 备选「顶部加「⋯」按钮菜单」：切换器行内空间窄、菜单语义不如右键直接，弃；子代理子项同样支持动作，保证不因嵌套而不可达。

### D4 共享代码就近搬迁

`containHomeWheel`（首页滚动约束）、`HOME_ROW` 与 `HOME_SECTION_LABEL`（侧栏行样式）当前从 `sessions.tsx` 导出；页面删除前迁入唯一使用方 `sessions-novel-sidebar.tsx`（`home.tsx` 与侧栏行样式共用），并更新 `home.tsx` 导入。其余仅页面内用的导出（搜索、分组、骨架等）随页面删除，不预提取、不保留死导出。

### D5 跨书搜索由命令面板承接，不新增聚合面

命令面板已能全局搜索会话并经 `openSessionRouted` 跳转书内；列表页搜索面板删除属于预期的能力收敛。不做替代页面或全局搜索增强（非目标）。

### D6 e2e 与回归套件同步迁移

- `novel/session-book-routing.spec.ts` 第一用例（书架会话行点击进书内）迁移为「从首页书架打开会话进书内右栏」；追加断言 `/sessions` 降级重定向到书架；深链绑定/未绑定两条用例不变（与列表页无关）。
- `regression/session-list-path-loading.spec.ts` 保留其守护意图（请求挂起不阻塞首屏可用性）：改为访问 `/sessions` 并断言降级重定向后书架首屏仍可用；不新增未加载的会话行断言（该行依赖的列表页保证已退役）。

## Risks / Trade-offs

- [共享导出遗漏导致删除后编译失败] → 删除前先全仓 grep `sessions.tsx` 的导出一一处置（迁移或内联），以 `bun typecheck` 为门。
- [切换器归档的级联不完整，遗留孤儿子代理] → 级联集合基于该书完整未归档会话列表计算（含子代理），存在子代时强制确认；e2e 断言子代理一并消失。
- [归档当前会话后面板停摆] → 依赖既有自动回跳（最近未归档会话/懒创建空态），在验收中显式验证该路径。
- [旧链接用户直达空白] → `/sessions` 降级重定向到书架，保底可达。
- [列表页删除损失跨书总览] → 已知且接受：书是唯一容器，命令面板保留全局查找；如需聚合面在后续首页重设计中单独立项。

## Migration Plan

单功能分支交付，纯 UI 层变更，无 schema/API 迁移、无 SDK 再生成（未触碰公开 Protocol 与 Server HttpApi）。回滚策略：revert 分支即可，遗留自由会话数据自始至终未动。
