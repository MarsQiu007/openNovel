# Spec Delta

## Purpose

约束会话时间线客户端的流式文本增量状态：增量必须按「所属消息 + part」复合身份隔离与清理，杜绝因 part ID 跨消息重复导致的正文串写、重复渲染与残留定格。

## ADDED Requirements

### Requirement: 流式增量按消息与 part 复合身份隔离
会话时间线客户端为流式 part 文本维护增量累积状态时，SHALL 以「所属消息 + part」的复合身份为作用域；即使不同消息的 part ID 相同，任一消息 part 的增量写入也不得改变其他消息任何 part 的累积状态或渲染文本。

#### Scenario: 两条消息 part ID 相同且先后流式
- **WHEN** 消息 A 与消息 B 各含一个同名 part（如同为 text-0），消息 B 正在流式追加文本
- **THEN** 消息 A 的该 part 渲染文本保持为消息 A 自己的内容，不出现消息 B 的任何片段

#### Scenario: 流结束后无跨消息残留
- **WHEN** 消息 B 流式完成、最终 part 状态已就位，消息 A 与消息 B 的 part ID 相同
- **THEN** 消息 A 渲染其自身 part 文本，消息 B 渲染其自身 part 文本，同一段文本不在多条消息上重复出现

### Requirement: 增量清理不得越界
当某个 part 被更新或移除、其所属消息被删除、或其所属会话被逐出缓存时，客户端 SHALL 仅丢弃该复合身份（或该消息、该会话范围内）的增量累积状态，不得丢弃其他消息或会话同 ID part 的累积状态。

#### Scenario: 一条消息清理时另一条消息的流式状态不受影响
- **WHEN** 消息 A 的 part 因最终更新而丢弃增量状态，消息 B 的同名 part 仍在流式中
- **THEN** 消息 B 的后续增量继续在其自身状态上累积，渲染连续不中断、不回退为过期文本

#### Scenario: 会话逐出只清自己的增量
- **WHEN** 某会话从缓存逐出
- **THEN** 该会话全部增量累积状态被丢弃，其他会话的增量累积状态不受影响

### Requirement: 无增量命中时回退 part 自身文本
渲染某个 part 的文本时，若该「消息 + part」复合身份下不存在增量累积状态，SHALL 回退显示该 part 自身携带的文本；增量命中时以累积状态优先。

#### Scenario: 无增量状态时显示 part 自身文本
- **WHEN** 某消息的 part 从未收到过流式增量
- **THEN** 该 part 渲染其自身携带的文本内容

#### Scenario: 有增量状态时显示累积文本
- **WHEN** 某消息的 part 正在流式且已有增量累积
- **THEN** 该 part 渲染累积文本而非过期的基础文本
