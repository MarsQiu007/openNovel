# Spec Delta

## Purpose

定义写作风格生成链路的端到端契约：用户在会话中请求生成或更新本书写作风格时，AI SHALL 基于小说既有设定推导风格内容、把参数化风格落库、把叙述性规范写入约定路径，保证风格产物必然可被协写作上下文消费，杜绝「风格 = 游离 md 文件」的默认行为。

## ADDED Requirements

### Requirement: 风格生成基于既有设定推导

编排 agent 收到用户生成或更新本书写作风格的请求时，SHALL 先获取该小说的既有设定概览（题材、梗概、世界观与角色要点）作为推导依据，再产出风格内容。prompt 契约 SHALL 写明此前置动作，使风格推导与书籍自身定位一致而非通用模板。

#### Scenario: 已有设定的书籍

- **WHEN** 用户请求为一本已落库题材与梗概的小说生成写作风格
- **THEN** agent 先读取设定概览再产出风格，风格内容与该书题材、梗概及既有设定呼应

#### Scenario: 尚无设定的书籍

- **WHEN** 用户请求为一本仅有书名与题材元数据的新书生成写作风格
- **THEN** agent 至少读取书籍元数据后推导风格，而非直接输出通用风格模板

### Requirement: 参数化风格以落库为交付完成标志

编排 agent 生成或更新风格时，基调、视角、时态与风格规则的参数化内容 SHALL 经设定保存工具的 style_guide 类型写入数据库；仅在对话中输出风格文本或仅产出文件而未落库，SHALL 视为交付未完成。

#### Scenario: 完整交付

- **WHEN** 用户请求更新写作风格且 agent 完成推导
- **THEN** 参数化风格被写入风格指南存储，后续协写作快照的风格指南段可渲染出新内容

#### Scenario: 仅输出未落库

- **WHEN** agent 在对话中输出了风格方案但未调用风格落库工具
- **THEN** 该次交付不视为完成，风格指南存储内容保持不变

### Requirement: 叙述性规范写入约定路径

若风格交付同时包含叙述性写作规范文本（叙事节奏、对话与描写比例、章节结构等长文），agent SHALL 将其写入分层写作规范的全书层约定文件（与协写作规范扫描范围一致的路径），使协写作上下文的写作规范段能够扫描到；agent 产出约定体系之外的说明性风格文件时，SHALL 向用户说明该文件不会被协写作消费。

#### Scenario: 规范文本进入约定路径

- **WHEN** agent 将叙述性写作规范写入全书层约定文件
- **THEN** 后续协写作快照的写作规范段可渲染出该规范内容

#### Scenario: 约定路径之外的产物

- **WHEN** agent 或用户把风格相关内容写到约定体系之外的文件
- **THEN** agent 告知该文件不会被协写作上下文消费，并引导迁移到约定路径或落库

### Requirement: 风格路由与权限一致性静态校验

系统 SHALL 提供静态校验测试，断言：编排 agent 提示词包含风格路由规则（先读设定、参数化落库、规范写约定路径）；风格落库工具对编排 agent 保持 allow、对创意发散 agent 保持 deny。提示词回退到无路由写法或权限表回退时，测试 SHALL 失败。

#### Scenario: 提示词包含风格路由

- **WHEN** 运行静态校验测试
- **THEN** 编排 agent 提示词中能检索到风格路由规则的关键内容

#### Scenario: 权限表回退

- **WHEN** 有人移除编排 agent 的风格落库工具 allow 或放开创意发散 agent 的 deny
- **THEN** 静态校验测试失败并指出不一致项
