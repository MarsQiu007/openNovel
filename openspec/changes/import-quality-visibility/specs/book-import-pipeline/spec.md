# Spec Delta

## MODIFIED Requirements

### Requirement: 汇总汇报随队列终结输出

「汇总汇报」单元 SHALL 在队列终结前产出全书整理汇总：纠错修订提案实数（已应用/待审/拒绝/失败）、设定候选待审数、技法新学/合并/拒绝清单、分章校验异常与简介生成确认，并 SHALL 明确提示待审入口位置（设定树的「清理修订」与「整理」审阅节点、书架待审角标）；队列完成（claim 无待处理单元）后 SHALL 调用 finish 终结队列并解除续跑约束。

#### Scenario: 收尾汇总并终结

- **WHEN** 全部单元完成（或受阻跳过）后执行汇总汇报单元
- **THEN** 输出含四类产出的实数汇总与待审入口指引，队列被 finish 终结，会话恢复正常停机语义
