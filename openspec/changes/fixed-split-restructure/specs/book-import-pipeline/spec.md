# Spec Delta

## ADDED Requirements

### Requirement: 固定分章识别

系统 SHALL 能识别按固定长度兜底导入的书籍：当全书章节标题整体呈现固定分章命名模式且各章长度均匀时，章节目录查询结果 SHALL 携带固定分章特征标记，供编排会话确定性判断，不依赖模型从标题自行猜测。

#### Scenario: 固定分章书籍被标记

- **WHEN** 编排会话查询一本按固定长度兜底导入的书籍的章节目录
- **THEN** 查询结果携带固定分章特征标记

#### Scenario: 正常解析书籍不标记

- **WHEN** 编排会话查询一本按章题正常解析导入的书籍的章节目录
- **THEN** 查询结果不携带固定分章特征标记

### Requirement: 建队前分章体检

导入整理创建队列时，若目标书籍携带固定分章特征标记，系统 SHALL 先执行分章体检：分析相邻章边界合理性并产出重切方案，向用户展示方案与影响；用户确认后先应用重切再基于新结构创建整理队列，用户拒绝或体检无需调整时按当前结构直接建队。未携带固定分章特征的书籍 MUST NOT 触发体检，按既有流程直接建队。

#### Scenario: 固定分章书籍先体检再建队

- **WHEN** 用户对固定分章书籍发起导入整理且体检产出非空重切方案
- **THEN** 系统向用户展示方案，确认应用后基于新章节结构创建整理队列

#### Scenario: 用户拒绝重切

- **WHEN** 体检产出重切方案但用户拒绝应用
- **THEN** 系统按当前章节结构创建整理队列，不执行任何结构修改

#### Scenario: 正常解析书籍不体检

- **WHEN** 用户对无固定分章特征的书籍发起导入整理
- **THEN** 系统不执行分章体检，直接按既有流程创建整理队列

### Requirement: 体检后队列校验语义不变

经体检重切后创建的整理队列，其分章结构校验单元 SHALL 保持只汇报语义：核对最终章节清单与边界并记录异常，不修改卷章结构；体检与应用重切 MUST NOT 发生在队列单元内。

#### Scenario: 重切后队列校验只汇报

- **WHEN** 固定分章书籍经确认重切后创建整理队列并执行分章校验单元
- **THEN** 校验单元只核对并记录新结构，不再提出或执行结构修改
