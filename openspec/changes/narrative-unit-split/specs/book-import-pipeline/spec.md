# Spec Delta

## REMOVED Requirements

### Requirement: 分章校验只汇报不重切

**Reason**: 规则兜底分章的书需要叙事定界能力（LLM 判断并按句调整边界），「只汇报不重切」的单元定位由「叙事定界单元」整体取代；章题完整连续的书的结构校验行为并入新单元。

**Migration**: 无持久化数据迁移；既有队列单元定义随版本更新，进行中的旧队列按既有断点语义续跑。

## MODIFIED Requirements

### Requirement: 队列单元按管线结构组织

队列 SHALL 按序包含：打头的全局「分章单元」一个（按书籍边界形态分派为结构校验或叙事定界）；随后每章一个「章节整理」单元（每章一条，含正文章）；收尾全局单元「书籍简介生成」与「汇总汇报」各一个。单元领取顺序 SHALL 与上述顺序一致，汇总汇报为最后一个单元。

#### Scenario: 建队单元清单

- **WHEN** 为 N 章已导入书籍创建整理队列
- **THEN** 队列含 N+3 个单元：分章单元打头、N 个章节单元按章序排列、简介与收尾殿后

## ADDED Requirements

### Requirement: 叙事定界单元

打头分章单元 SHALL 按书籍边界形态分派行为：章题完整连续的书执行结构校验（核对章节清单与边界，含序章/番外/章号缺口/重号，只汇报不重切）；规则兜底分章的书执行叙事定界——逐章调用 `cutter` 判断边界并按结论调整（定界→分段重建→章节清洗建议），定界结果自动应用并记入进度笔记与最终汇总（前后章界对照），用户可凭整书存档回滚；定界 MUST NOT 增删章数，过短末章允许并入前章。

#### Scenario: 有章题书结构校验

- **WHEN** 章题完整连续的书执行打头单元
- **THEN** 核对章节清单与边界并记录异常，卷章结构保持导入后的原样不变

#### Scenario: 兜底分章书叙事定界

- **WHEN** 规则兜底分章的书执行打头单元
- **THEN** 逐章完成定界判断、按句调整与分段重建，结果自动应用并记录前后章界对照

#### Scenario: 定界可回滚

- **WHEN** 用户对定界结果不满意
- **THEN** 可凭整书存档将章节结构恢复到定界前状态

### Requirement: 建队前成本估算展示

创建含叙事定界的整理队列前，系统 SHALL 展示 LLM 调用量估算（章数 × 单次边界上下文 token 量级）与降级说明；估算 MUST NOT 阻断建队，用户确认后继续。

#### Scenario: 建队展示估算

- **WHEN** 用户对兜底分章的书点击「AI 整理」
- **THEN** 建队前展示调用量估算与降级说明，确认后创建队列

#### Scenario: 有章题书不展示定界估算

- **WHEN** 章题完整连续的书点击「AI 整理」
- **THEN** 不展示叙事定界估算，按既有流程建队
