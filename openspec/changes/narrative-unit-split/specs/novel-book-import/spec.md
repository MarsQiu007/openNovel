# Spec Delta

## ADDED Requirements

### Requirement: 整书原文存档

导入建书时系统 SHALL 将原文完整存档（文件存档并入库元数据：内容哈希、编码、字数），存档随书删除；叙事定界与导入后整理 SHALL 从存档读取原文，不依赖用户重新上传。无存档的存量书籍定界功能不可用，但不影响其既有功能。

#### Scenario: 建书即存档

- **WHEN** 用户确认导入完成建书
- **THEN** 原文已存档且元数据入库，后续定界从存档读取

#### Scenario: 存档随书删除

- **WHEN** 用户删除一本书
- **THEN** 该书的原文存档与元数据一并删除

#### Scenario: 存量书无存档不阻断

- **WHEN** 对本提案前导入的书籍发起整理
- **THEN** 定界步骤跳过并提示该书无存档，其余整理单元正常执行
