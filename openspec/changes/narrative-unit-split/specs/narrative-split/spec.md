# Spec Delta

## Purpose

让无章题书籍的章节边界由 LLM 按叙事单元判定：`cutter` 专用 agent 在字数粗切的基础上逐章定界（边界是否落在叙事单元、按句增减调整、章内分段重建），以边界上下文代替通读全书控制成本，规则切分保留为无模型时的降级路径。

## ADDED Requirements

### Requirement: 定界输入为边界上下文

`cutter` 执行定界时 SHALL 只读取待判章的首部与尾部各若干句及相邻章的衔接句作为上下文，MUST NOT 通读全书或整章全文。上下文规模 SHALL 有上限并在 agent 契约中固定。

#### Scenario: 单章定界只读边界

- **WHEN** 队列对一章执行定界判断
- **THEN** 该次调用仅包含本章首尾各若干句与相邻章衔接句，不含全书或其他章全文

### Requirement: 定界输出结构化结论

`cutter` 对每章 SHALL 输出结构化定界结论：边界成立、前移 N 句或后移 N 句，以及章内分段点列表；输出 MUST 可被确定性解析，解析失败按降级处理。

#### Scenario: 结构化定界结论

- **WHEN** 一章的定界判断完成
- **THEN** 输出含明确结论（成立/前移/后移 + 句数）与章内分段点，可被机械解析执行

### Requirement: 按句增减迭代与硬约束

定界调整 SHALL 按句为单位移动切点，迭代不超过 3 次；每次调整后的切点 MUST 落在句末且引号配对闭合；调整 MUST NOT 增删章节数量，过短末章允许并入前章；调整后章字数越出目标范围时 SHALL 按既有规则二次收束。

#### Scenario: 迭代收敛

- **WHEN** 某章边界判断为需调整
- **THEN** 按句移动切点并复判，至多 3 次后取当前最优边界，不无限迭代

#### Scenario: 切点硬约束

- **WHEN** 调整后的切点不满足句末或引号闭合
- **THEN** 该切点被拒绝并继续按句搜索最近合法位置

### Requirement: 章内分段重建

定界完成后 SHALL 按 `cutter` 输出的分段点重建该章段落结构（对话轮次与场景转换为分段依据）；分段重建 MUST NOT 增删或改写正文文字，只插入段落边界。

#### Scenario: 段落重建不改正文

- **WHEN** 一章完成分段重建
- **THEN** 章内按分段点形成段落，全部文字与定界后正文逐字一致

### Requirement: 模型解析与降级

`cutter` 的模型 SHALL 经既有 `agent.cutter.model` 配置链解析，未配置时按既有继承链回落，导入与整理全程无需用户额外配置。无可用模型或调用失败时 SHALL 降级为规则切分结果直接可用，不阻塞导入与后续整理。

#### Scenario: 配置链回落

- **WHEN** 用户未为 `cutter` 配置模型
- **THEN** 按既有继承链取得模型执行定界，导入流程无额外交互

#### Scenario: 无模型降级

- **WHEN** 定界执行时无可用模型或调用失败
- **THEN** 该章采用规则切分边界与规则分段，流程继续且不中断队列
