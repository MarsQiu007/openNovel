# Proposal

## Why

会话列表页退役后，子代理会话只存在于书内切换器的折叠收纳区：默认折叠、斜体弱化、需要两次点击才能进入。用户在主会话看得到并发输出，却找不到「是谁在干活、干到哪了」——2026-10-27 用户明确反馈「之前可以进到子代理的专门会话中看在做什么，这个版本不行了」，并追问「子代理默认不展开不好吗」。功能链路完好（数据、路由、e2e 均在），退化纯在可发现性层。

## What Changes

- 书内会话切换器：子代理节点改为**默认展开**（用户手动收起才折叠），取消「默认折叠 + 需手动展开」的现状；运行中的子代理条目显示行内运行指示，结束后指示消失。
- 会话时间线视图：当前会话存在运行中的直接子代理时，时间线上方显示**活跃子代理横条**——逐条列出运行中的子代理（标题 + 运行指示），点击直接进入该子代理会话；全部结束后横条自动消失。
- 横条与切换器的运行指示共用同一会话运行状态来源，不新增后端端点与轮询。

## Capabilities

### New Capabilities

- `subagent-session-visibility`: 子代理会话在工作台界面的可见性——切换器默认展开与运行指示、时间线上方的活跃子代理横条、以及两者对子代理开始/结束运行的实时响应。

### Modified Capabilities

（无——现有 `novel-session-activity` 只定义书籍级活动判定，不涉及逐个子代理的展示；本能力与其共用运行状态来源但行为不重叠。）

## Impact

- **packages/app**：书内会话切换器（展开语义反转 + 运行指示）、会话时间线视图（新增活跃子代理横条组件及挂载）。可能触碰既有 e2e 断言（`session-switcher-subagent.spec.ts` 的「默认折叠」链路需改为「默认展开」）。
- **packages/core / packages/protocol / packages/server**：无改动——运行状态复用现有 per-session 状态推送与 active 集合对账机制；子代理集合复用现有会话列表/绑定树数据。
- **兼容性**：纯 UI 层变更，无数据迁移；首页会话侧栏的既有嵌套展示不受影响。
- **非目标**：
  - 不把子代理的输出流内嵌到主会话时间线（进入子会话查看的方式不变）；
  - 不改子代理调度、深度限制、权限等执行语义；
  - 不展示已结束/已归档子代理于横条（历史经默认展开的切换器可达）；
  - 新增界面文案沿用书内面板内联中文先例，不新增 i18n locale key；
  - 首页侧栏展示逻辑不在本变更范围（书内工作台优先）。
