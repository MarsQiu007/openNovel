## Why

地图数据层与只读渲染就绪后，用户仍无法亲手创建和调整世界地图。AI 生成（后续提案）也需要人工修正能力兜底。需要提供手动编辑器，让用户绘制区域、放置地点、安放角色图钉，并在草稿工作流中安全地保存。

## What Changes

- 草稿工作流入口：无草稿时支持"从正式地图派生草稿"（复制全部要素与图钉）或"空白草稿"两种创建方式。
- 在草稿上编辑：区域多边形绘制（点击落点、闭合）、命名地点放置、拖拽移动、坐标数值面板微调。
- 要素与图钉的创建、编辑、删除，操作即时防抖保存到既有 CRUD API。
- 世界观条目选择器（关联要素）与角色选择器（安放图钉），保持既有"删除世界观只断关联"语义。
- 草稿完成后走既有的强确认提升流程（ADR-0001，复用渲染提案的确认交互）。

### 非目标

- 不实现 AI 生成。
- 不实现层级/LOD、路线绘制、装饰图层。
- 不支持直接编辑正式地图（一切编辑先入草稿）。

## Capabilities

### New Capabilities

- `world-map-editing`: 世界地图草稿的手动编辑能力，包括草稿派生、要素绘制与拖拽、图钉安放、即时保存与关联选择。

### Modified Capabilities

_none_

## Impact

- packages/app：地图视图扩展编辑模式；新增绘制工具条、属性面板、选择器组件。
- 复用 packages/client 世界地图 CRUD API 与世界观/角色查询 API。
- 无 schema/protocol 变更，无数据迁移。
