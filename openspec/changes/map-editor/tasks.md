## Tasks

### 草稿工作流

- [ ] 草稿创建入口：从正式地图派生（循环复制要素与图钉）与空白创建。
- [ ] 编辑模式入口：已有草稿时地图视图提供"编辑草稿"进入编辑态。

### 绘制与编辑

- [ ] 区域绘制工具：点击落点、临时预览、闭合/取消。
- [ ] 地点放置工具与拖拽移动（要素、图钉），释放时保存最终坐标并钳制 0..10000。
- [ ] 区域顶点拖拽编辑：选中区域显示顶点手柄，拖拽改形并保存。
- [ ] 属性面板：名称、描述、颜色编辑；世界观条目选择器；角色选择器与图钉唯一性前置校验。
- [ ] 要素与图钉删除（含确认提示）。

### 保存与恢复

- [ ] 放弃草稿：二次确认后删除草稿及其内容，返回地图视图。
- [ ] 操作防抖自动保存与失败重试提示。
- [ ] beforeunload 未保存变更提示。

### 验证

- [ ] packages/app bun typecheck 通过。
- [ ] 手动验证：派生/空白创建、绘制、拖拽、关联、唯一图钉拒绝、保存失败重试。
- [ ] openspec validate map-editor --strict 通过。
