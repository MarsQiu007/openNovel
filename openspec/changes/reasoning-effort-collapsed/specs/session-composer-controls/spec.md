# session-composer-controls Delta

## MODIFIED Requirements

### Requirement: 推理档位分段常驻与内容伸缩

模型选择弹层 SHALL 常驻呈现"推理档位"收纳行（档位标签 + 当前档位值 + 展开指示），档位列表收纳于行内：用户点击收纳行后在其下方行内展开档位列表（default 首项 + 全部声明档位），再次点击收起；选择档位后列表收回，收纳行与模型芯片同步显示当前档位值。未声明推理档位的模型收纳行仍常驻显示 default，展开后仅呈现 default 弱化单项与提示文案。控件栏本身不再承载独立的推理档位控件。分段内默认档 SHALL 为 default；用户选中非默认档位时，模型芯片 SHALL 显示档位后缀。

#### Scenario: 模型支持推理档位

- **WHEN** 用户切换到一个配置了推理档位的模型并打开模型选择弹层
- **THEN** 弹层常驻呈现收纳行并显示当前档位值；用户点击收纳行后行内展开档位列表（default 首项与全部声明档位），选中非默认档位后列表收回，模型芯片显示"模型名 · 档位"形式的后缀

#### Scenario: 模型不支持推理档位

- **WHEN** 用户切换到一个未配置推理档位的模型并打开模型选择弹层
- **THEN** 收纳行仍常驻并显示 default；用户点击展开后分段内仅含 default 一项且以弱化样式与提示文案标示无可用档位；控件栏不残留推理档位占位或禁用控件，模型芯片不显示档位后缀

#### Scenario: 无档位模型提交不注入推理参数

- **WHEN** 用户对一个未配置推理档位的模型（弹层分段仅含 default）发起会话
- **THEN** 提交请求不携带任何推理档位参数，会话按模型缺省行为执行

#### Scenario: 收纳行展开与收起

- **WHEN** 用户打开模型选择弹层看到收纳行
- **THEN** 点击收纳行在其下方展开档位列表且指示翻转，再次点击收起；整个过程中收纳行始终显示当前档位值，展开态不影响模型列表的选择行为
