# Spec Delta

## MODIFIED Requirements

### Requirement: 读取侧与写入侧同构归一化

读取 style_guide.rules（书籍风格面板、设定检查工具、内嵌阅读器风格页）时，系统 SHALL 使用与写入侧相同的归一化规则：历史嵌套对象、数组与 JSON 字符串形态均归一化为扁平字符串映射后输出。风格编辑面板 SHALL 以规则行（键与值成对控件）展示归一化后的规则，原样保存后映射保持不变；设定检查工具与内嵌阅读器风格页 SHALL 继续以每行一条 `键: 值` 的文本形态展示。

#### Scenario: 历史嵌套数据可读

- **WHEN** 库中存有嵌套对象形态的历史 rules
- **THEN** 风格编辑面板、检查工具与内嵌阅读器显示展平后的规则（面板为规则行，工具与阅读器为规则行文本），不显示为空或占位符

#### Scenario: 历史数组数据可读

- **WHEN** 库中存有数组形态的历史 rules
- **THEN** 显示为索引键的规则，条目内容不变

#### Scenario: 展示与回存一致

- **WHEN** 用户不改动面板内容直接保存
- **THEN** 库中映射与面板展示一致，条目数量与值均不变化
