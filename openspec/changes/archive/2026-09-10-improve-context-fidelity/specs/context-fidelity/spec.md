## Purpose

约束上下文组装与状态提取环节的信息保真:上一章结尾窗口的覆盖长度、章节摘要的结构化要素、
快照对结构化要素的渲染与降级、情绪一致性检测对状态转移的消费,以及 writer 起草前必须持有
本章章纲的兜底保障——共同收窄因摘要链过度压缩导致的长程情节漂移。

## ADDED Requirements

### Requirement: 上一章结尾窗口
上下文快照必须向 writer 提供上一章正文的结尾内容作为衔接窗口,长度为上一章正文的最后
1500 字;上一章正文不足 1500 字时必须提供其全部正文。上一章不存在时本要求不适用。

#### Scenario: 上一章正文超过 1500 字
- **WHEN** 组装写作快照且上一章正文超过 1500 字
- **THEN** 快照中的上一章结尾内容为其正文的最后 1500 字

#### Scenario: 上一章正文不足 1500 字
- **WHEN** 组装写作快照且上一章正文不足 1500 字
- **THEN** 快照包含上一章全部正文

### Requirement: 章节摘要的结构化提取
状态提取 agent 产出章节摘要时,摘要正文长度必须控制在 400-500 字,且必须明确包含三要素:
本章时间点、主要地点、角色情绪转折;关键事件列表必须支持结构化情绪转移条目,格式为
`情绪转移:角色名:从X因Y变成Z`。本章无明显情绪转折时不强制生成情绪转移条目。

#### Scenario: 提取含情绪转折的章节
- **WHEN** 对一个存在角色情绪转折的章节执行章节摘要提取
- **THEN** 摘要正文在 400-500 字内覆盖时间点、地点、情绪转折三要素
- **AND** 关键事件列表含至少一条 `情绪转移:` 前缀条目

#### Scenario: 提取无情绪转折的章节
- **WHEN** 对一个没有明显角色情绪转折的章节执行章节摘要提取
- **THEN** 摘要正文仍覆盖时间点与地点要素,不强制生成情绪转移条目

### Requirement: 快照摘要的结构化渲染
快照的最近章节摘要段必须展示摘要的时间点、地点、情绪转移要素;摘要缺少结构化要素时
(历史数据),必须按原有纯文本格式渲染,不得导致快照组装失败或要素误标。

#### Scenario: 渲染含结构化要素的摘要
- **WHEN** 组装快照时最近章节摘要包含时间、地点、情绪转移要素
- **THEN** 该摘要在快照中单独展示三要素

#### Scenario: 渲染历史格式摘要
- **WHEN** 组装快照时最近章节摘要为不含结构化要素的历史数据
- **THEN** 按原有纯文本格式渲染,快照组装不失败

### Requirement: 情绪一致性检测消费状态转移
情绪突变检测必须优先基于相邻章节的情绪转移条目进行状态转移比对;情绪转移条目不存在时,
必须回落到现有的情绪点状态比对,行为保持不变。非 `情绪转移:` 前缀的关键事件条目不受影响。

#### Scenario: 相邻章节含情绪转移条目
- **WHEN** 连续性审计中相邻章节摘要含 `情绪转移:` 条目
- **THEN** 情绪突变检测基于转移条目判断,而非对两个独立的情绪点状态直接比对

#### Scenario: 相邻章节无情绪转移条目
- **WHEN** 连续性审计中相邻章节摘要不含 `情绪转移:` 条目
- **THEN** 情绪突变检测回落到现有情绪点状态比对逻辑

### Requirement: 起草前的章纲保障
writer dispatch 必须携带本章章纲。快照输出不含本章大纲段时,pipeline 必须先通过章纲读取
工具取得章纲全文并入 dispatch prompt,再 dispatch writer;章纲既不在快照也无法读取时,
pipeline 必须停止并报告该章大纲缺失,禁止 dispatch writer 裸写。驳回重写分支不依赖章纲,
不受本要求约束。

#### Scenario: 快照含本章大纲
- **WHEN** 快照输出包含本章大纲段
- **THEN** pipeline 直接携带该章纲 dispatch writer,现行为不变

#### Scenario: 快照缺章纲但章纲可读
- **WHEN** 快照输出不含本章大纲段
- **THEN** pipeline 先调用章纲读取工具取得全文,将其并入 dispatch prompt 后再 dispatch writer

#### Scenario: 章纲完全缺失
- **WHEN** 快照无本章大纲段且章纲读取工具无法取得章纲正文
- **THEN** pipeline 停止流水线并向用户报告该章大纲缺失、需人工介入,不 dispatch writer

### Requirement: 章纲读取工具返回正文
章纲读取工具必须返回章纲正文与章节元信息;对应章纲正文缺失时,必须返回元信息并明确注明
正文缺失,不得报错中断。

#### Scenario: 章纲正文存在
- **WHEN** 调用章纲读取工具且该章章纲正文存在
- **THEN** 输出同时包含章节元信息与章纲正文

#### Scenario: 章纲正文缺失
- **WHEN** 调用章纲读取工具且该章章纲正文不存在
- **THEN** 输出包含章节元信息并明确注明正文缺失,工具不失败
