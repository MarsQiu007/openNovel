# Spec Delta

## ADDED Requirements

### Requirement: 固定长度兜底预览再生

未识别章节边界时，用户切换固定长度分章开关后，系统 SHALL 使用当前解析选项重新分析并刷新预览与确认令牌；新预览就绪前系统 MUST NOT 允许确认导入。重新分析 SHALL 保留用户已编辑的书名。

#### Scenario: 开启固定长度兜底

- **WHEN** 导入预览报告未识别章节边界，用户开启按固定长度分章
- **THEN** 系统重新分析并展示固定长度生成的卷章预览，确认后导入成功且不提示预览过期

#### Scenario: 重新分析期间禁止确认

- **WHEN** 用户切换固定长度分章开关且重新分析尚未完成
- **THEN** 确认导入入口不可用，应用不会提交旧预览令牌

#### Scenario: 关闭固定长度兜底

- **WHEN** 用户重新关闭按固定长度分章
- **THEN** 系统重新分析并恢复未识别边界的提示与空卷章预览
