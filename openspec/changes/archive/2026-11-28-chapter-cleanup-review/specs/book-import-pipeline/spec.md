# Spec Delta

## MODIFIED Requirements

### Requirement: 纠错建议禁止直改正文

纠错阶段 SHALL 逐章产出错别字与残留格式问题建议，每条含章节定位与原文/建议对照；建议 SHALL 以结构化修订提案落库进入清理修订审阅（类型、锚点、原文引用、建议文本、理由、置信度），纠错产出 MUST NOT 直接修改章节正文，正文变更仅发生在用户于审阅面板接受后的确定性应用中。

#### Scenario: 产出建议且正文不变

- **WHEN** 章节整理单元的纠错阶段发现错别字
- **THEN** 该条建议以修订提案落库为待审状态，该章正文内容未被修改

#### Scenario: 队列终结后建议仍可审

- **WHEN** 整理队列完成终结
- **THEN** 纠错阶段落库的修订提案在清理修订审阅面板仍逐条可见可操作，不随队列终结丢失
