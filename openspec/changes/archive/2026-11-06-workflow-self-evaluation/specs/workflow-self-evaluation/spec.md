# Spec Delta

## Purpose

回顾创作流程中工具与创作方法的表现，持续积累项目级指标，产出面向作者与开发者的三分部优化建议报告，并支持用户自愿导出分级脱敏诊断包以反馈产品信号。

## ADDED Requirements

### Requirement: 指标滚动积累
系统 SHALL 以本地项目级指标桶持续积累创作过程指标：会话事件（token/工具调用/压缩/取消）惰性计数，以及创作管线既有判定点（召回、预算裁剪、守卫、审批、技法注入、钩子轮换、弧光、结构、连续性）旁的增量埋点。指标 MUST 只增计数与聚合统计，不采集小说正文；埋点失败 MUST 仅记日志，不得阻断写作。

#### Scenario: 惰性事件计数
- **WHEN** 一个携带 token 用量的会话 step 事件被持久化
- **THEN** 指标桶中对应 agent 与模型的 token 计数被增量更新

#### Scenario: 判定点埋点
- **WHEN** 上下文打包发生 P0-P7 任一级预算裁剪
- **THEN** 该级裁剪计数与裁剪量被记入指标桶，且打包结果不变

#### Scenario: 埋点失败降级
- **WHEN** 指标写入因 IO 失败
- **THEN** 仅记录警告日志，创作流程正常继续

### Requirement: 三分部报告
系统 SHALL 支持生成 Markdown 报告，含三分部：A 创作复盘（卡壳地图、修改热点、进度节奏，面向作者）、B 配置优化（预算裁剪热点与模式切换等建议，v1 纯文本不代应用）、C 产品信号（七域指标：运行时健康、提示词控制、设定召回、上下文拼接、创作流程、技法系统、叙事质量，附失败分类法与复现要点，面向开发者）。报告 MUST 由确定性规则从指标桶与本地数据生成，MUST NOT 调用 LLM。

#### Scenario: 手动生成报告
- **WHEN** 用户在插件中手动触发自评价（默认范围为上次报告以来）
- **THEN** 生成含三分部的报告并写入项目 evaluate 目录，附生成时间与覆盖范围

#### Scenario: 报告不消耗模型
- **WHEN** 报告生成执行
- **THEN** 全程无 LLM 请求，所有章节由规则模板与指标数据填充

#### Scenario: 空数据报告
- **WHEN** 覆盖范围内无任何指标数据
- **THEN** 报告标注数据不足并仅输出已有内容，不编造建议

### Requirement: 自动触发策略
系统 SHALL 在以下时机自动生成报告：卷完结、会话压缩完成、反复修改滚动窗超阈值（rollback/审批拒绝/大改达阈值）、会话数周期兜底。同项目自动报告 MUST 有 24 小时冷却并合并同类信号；手动触发不受冷却限制。自动生成 MUST 为后台任务，不阻塞写作、不弹打断式对话框。

#### Scenario: 压缩后自动报告
- **WHEN** 一次会话压缩完成且不在冷却期
- **THEN** 后台生成报告，作者可在 evaluate 目录查阅

#### Scenario: 冷却去重
- **WHEN** 冷却期内再次命中自动触发信号
- **THEN** 不生成新报告，信号仅计入指标桶

#### Scenario: 手动优先
- **WHEN** 用户在冷却期内手动触发
- **THEN** 立即生成报告，不受自动冷却影响

### Requirement: 诊断包分级导出
系统 SHALL 支持导出诊断包供用户自愿随反馈分享：L0 纯计数、L1 附错误分类样本（截断脱敏，默认）、L2 附复现事件序列。诊断包 MUST NOT 包含小说正文；genre 题材值 MUST NOT 出现在 L0/L1；任何导出 MUST 由用户显式命令触发，系统不得自动外发。

#### Scenario: 默认 L1 导出
- **WHEN** 用户执行诊断包导出且未指定级别
- **THEN** 生成含七域计数与截断错误分类样本的 JSON，不含正文与题材值

#### Scenario: L2 复现序列
- **WHEN** 用户显式指定 L2 导出
- **THEN** 诊断包附复现事件序列，并在导出结果中提示其可能含题材信息

#### Scenario: 无自动外发
- **WHEN** 报告或诊断包生成
- **THEN** 无任何网络上传行为，文件仅存于项目本地
