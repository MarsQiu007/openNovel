# 设计：书内会话切换器

## Context

绑定会话数据模型本就支持 1:N（`NovelSessionBinding` 为列表，绑定关系按 novelID 过滤），但消费 UI 全部按 1:1 生长：工作台对话面板只渲染路由 `/:dir/novel/:novelID/session/:id` 中的那个会话；主线写作流（`findBoundNovelSession`）取"第一个未归档绑定会话"。本书内没有会话列表、切换、轻创建的任何界面。

对话面板已常驻挂载（display 切换保持会话状态），工作台路由以 `params.id` 承载当前会话——切换器的全部联动机制都是现成的。

## Goals / Non-Goals

**Goals:**

- 书内会话的切换与轻创建获得工作台内的一等入口，1:N 模型的 UI 缺口补齐
- 切换零重置：复用对话面板常驻挂载与路由联动，主区/左栏不受影响

**Non-Goals:**

- 不做会话重命名、解绑、归档的管理 UI（归档沿用既有级联；重命名在会话内已有）
- 不动主线写作流（WritingFlowButton 的"找第一个/创建并写下一章"语义保持）
- 不做生成状态徽标、最近活动时间等列表信息增强（实施期走查信息密度后再议）

## Decisions

### D1：切换器形态——对话面板顶部常驻一条

当前会话标题 + 下拉箭头 + 新建按钮，占据对话面板顶部一行。备选否决理由：右栏新增"会话"面板——高频切换动作埋进面板太深；左栏加"会话"分段——会话非内容资产，与章节/大纲/设定异质，且需要跨区联动。

### D2：切换 = 路由联动，无独立状态

选择列表项 → 更新工作台路由 `session/:id` 段（与 expand 态 `?tab=` 同一机制层级）。`params.id` 是当前会话的唯一事实来源，对话面板按其渲染。SessionPage 按会话 ID 挂载、`SessionRouteErrorBoundary` 已有，切换即挂载目标变化；SessionProviders（Terminal/File/Prompt/Comments）均不按会话 ID keyed，常驻挂载下切换不重建组件树，切回时 solid-query 缓存恢复对话内容。滚动位置不纳入保证：滚动容器位于常驻面板层，无按会话记忆，往返后滚动位置不保证恢复（目标会话内容较短时浏览器会 clamp scrollTop）——如走查发现体验问题，另议按会话滚动记忆。

无绑定会话（空态）时整个对话面板维持现有 fallback（写作按钮引导），不渲染切换器——切换器仅在存在绑定会话时出现，不新增第四种面板形态。

### D3：查询组合——绑定关系 × 会话列表，复用既有模式

`listSessionBindings()`（已有）与 `session.list()` 取交集并过滤未归档——与 `findBoundNovelSession` 相同的查询模式，差异仅在返回**列表**而非第一个。走 novel-queries 的查询缓存，新建/归档会话后失效重取。

### D4：新建轻会话——创建 + 绑定 + 切入，不带 prompt

创建会话（标题用书名，与主线创建一致，用户可后续在会话内改名）→ 绑定该书 → 路由切入新会话。与 WritingFlowButton 的职责边界：主线按钮 = "开始写下一章"（带自动 prompt 的工作流），切换器新建 = "开一条对话线"（裸会话）。

### D5：1:N 下主线流的"第一个"语义不动（记录在案）

`findBoundNovelSession` 返回第一个未归档绑定会话——多会话成为常态后，主线按钮可能不指向用户正在编辑的会话。本 change 不修改该语义（超范围）；若走查确认困扰，另开提案（如改为"最近活跃的绑定会话"）。

## Risks / Trade-offs

- [生成任务进行中切换会话] → 常驻挂载下原会话继续在后台生成，novelActivity 为全局信号不受影响；切回可见进度。走查验证一次。
- [下拉列表信息密度不足（仅标题）] → 最低可用；标题即用户命名习惯的主标识。增强项列入 Non-Goal 待走查后定。
- [切换器与 expand 态（主区焦点）并存] → expand 态下对话面板收为窄条，切换器随面板隐藏，不产生新形态；Esc 返回 peek 后恢复。
- [滚动位置往返不恢复] → 滚动容器在常驻面板层、无按会话记忆，切换往返后 scrollTop 不保证回到原位（D2 已声明不纳入保证）；若走查确认体验受损，另议按会话滚动记忆，不在本 change 内实现。

## Migration Plan

单分支纯前端改动（一个组件 + 查询组合），`bun typecheck` + oxlint + bun test 通过后走查。回滚 `git revert` 即可，无持久化格式变更。
