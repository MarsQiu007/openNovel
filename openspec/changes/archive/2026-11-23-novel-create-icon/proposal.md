# Proposal

## Why

书架页「创建小说」按钮引用了未注册的 `add` 图标，开发环境持续出现缺失告警，按钮图标位置渲染为空白，削弱了新建入口的可识别性。该问题已在桌面开发控制台中暴露，应补齐图标语义。

## What Changes

- 为 V2 图标注册表补充创建语义的 `add` 图标资产。
- 保持「创建小说」按钮继续引用 `add`，使按钮显示明确的加号/创建图标。
- 不改变「创建小说」的入口位置、文案、导航目标、禁用规则或其他书架交互。
- 不处理开发控制台中的重复命令 ID 与字体加载提示。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `novel-bookshelf`: 新增「创建小说」入口图形语义要求，要求创建入口显示创建语义图形，避免未注册图标导致空白。

## Impact

- 受影响包：`packages/ui`（图标注册表）、`packages/app`（书架页使用方）。
- 不影响 `novel-store`、`plugin`、`opennovel`、`desktop` 的运行时逻辑、数据模型或 API 契约。
- 不涉及本地数据兼容性迁移；已有书架与新建小说向导行为保持不变。
- 验证重点：开发环境不再出现 `未注册的图标名 "add"`，且「创建小说」按钮显示创建语义图标。
