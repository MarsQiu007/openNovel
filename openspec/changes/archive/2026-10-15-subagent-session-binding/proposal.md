# Proposal

## Why

会话经 session-book-only 与 retire-sessions-page 收敛为「书是唯一容器」后，子代理会话的进入与运行仍依赖一个不可靠的隐式假设：只有「目录恰好只有一本书」时，子代理才会被懒绑定顺带标记。多书项目产生的子代理没有绑定行——点击其时间线卡片会被重定向宿主判定为「未绑定」，弹回书架（真实数据已踩中：XianXia 项目「生成第4章章纲 (@outliner subagent)」子代理会话无绑定，点击即降级）；同一批会话运行时的工具门禁与上下文注入也因解析不到书籍而静默失效（大纲/设定类工具报「未找到当前小说项目」、系统快照与灵魂注入被跳过）。

绑定不是可选标记，而是「会话归属书籍」的运行时不变量：子代理会话与用户会话一样，必须能沿父会话链解析出唯一归属书籍。本变更把这一契约在写侧（持久化继承）、读侧（导航兜底）与展示侧（切换器集合）统一落地，修复「从右侧会话点不开子代理」的用户路径，并连带修复子代理运行时的工具与上下文链路。

## What Changes

- 建立「会话归属解析」契约：会话的归属书籍按「自身绑定行 → 沿父会话链最近一个有绑定行的祖先 → 无归属」解析；无归属的遗留会话维持既有降级（书架 + 提示）。
- 子代理会话运行继承：子代理会话首次运行时沿父会话链继承最近绑定祖先的书籍归属，并幂等持久化绑定行；多书项目同样生效。工具的书籍解析与系统上下文注入随之一并对子代理生效。
- 导航兜底：所有「打开会话」入口（时间线子代理卡片、命令面板、首页会话卡片、外部深链）在会话自身无绑定行时按归属解析进入祖先所属书籍的工作台打开该会话；仅无归属会话降级。
- 书内切换器多级化：切换器覆盖「该书绑定主会话 + 其全部子代理后代（任意层级、不要求后代自身有绑定行）」，后代按父链递归嵌套收纳、默认折叠；孙级子代理重获可见入口。
- 自动回跳与会话集合对齐：按书记忆回跳覆盖任意层级子代理会话；无有效记忆时回落最近活跃的主会话，避免把用户意外拉入只读的产物会话。
- 书籍活动与批注占用判定覆盖子代理后代：子代理运行计入所属书籍的活动状态与执行占用。

## Capabilities

### New Capabilities

（无——本变更收敛既有能力的边界，不引入新的系统能力。）

### Modified Capabilities

- `titlebar-tabs`：「会话归属书籍」升级为归属解析契约——子代理会话运行继承并持久化归属；未绑定遗留会话的降级条件收紧为「整条父链无绑定」。
- `novel-workspace-layout`：「绑定会话统一在工作台打开」与「书内会话切换」——所有打开入口按归属解析兜底（子代理会话经祖先归属进入书籍工作台）；切换器集合定义升级为「绑定主会话 + 全部后代」。
- `novel-chat-panel`：切换器与回跳相关的六个 requirement 对齐归属会话集合——列表集合含未绑定后代、嵌套支持任意层级、回跳集合含全部后代，并将空态入口、查询失败自愈、会话归档的表述统一到归属术语。
- `novel-session-activity`：活动与占用判定对齐归属会话集合——书籍级活跃判定、活跃状态实时更新、执行面板共用判定统一覆盖子代理后代。

## Impact

- **packages/plugin**：写作工具的书籍解析路径扩展为归属继承（工具门禁、系统上下文与灵魂注入、压缩注入）。
- **packages/novel-store**：会话归属解析支持沿父链回溯（保持包边界与既有单书懒绑定兼容）。
- **packages/app**（主要改动面）：会话路由决策纯函数与重定向宿主、统一打开动作；切换器列表构建（递归嵌套）、自动回跳、活动判定输入；切换器渲染多级菜单。
- **e2e 与单元测试**：新增/扩展未绑定子代理导航、多级嵌套、归属继承、回跳与活动用例；现有已绑定路径用例保持。
- **packages/opennovel / desktop / schema / protocol / client**：无改动，无需重新 generate。
- **数据兼容性**：不删数据、不迁移 schema；存量未绑定子代理经读侧解析立即可访问，写侧在下次运行时自愈补写绑定行；无归属的遗留自由会话行为不变。
- i18n locale 文件保持不动。
