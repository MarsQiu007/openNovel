# Proposal: style-rules-pipeline

## Why

当 agent 为书籍生成写作风格时，风格规则会在保存环节被静默丢弃：写入工具只保留顶层标量值，agent 给出的两层嵌套规则（如 `"异能体系": {"等级严格": "…"}`）被归一化成空映射 `{}` 落库，工具却返回"已保存"成功，用户在「写作风格」面板看到规则为空。已用真实数据实锤：《执棋人》rules 为 `{}`，而完整的九大类规则（约 2680 字）存在于会话日志中。此外，即使规则以扁平形态正确落库（如《我有一方小天地》），写作快照也从不渲染规则（仅基调/视角/时态），自由规则实际约束不到 writer——"存"与"用"两处链路都是断的。

## What Changes

- 规则写入统一归一化（新契约，覆盖设定保存工具 / 状态提交管线 / 风格指南更新接口 / 书籍元数据联合保存）：style_guide.rules 按"扁平字符串映射"归一化后落库——嵌套对象按 `父.子` 键递归展平、数组按索引展平、字符串先按 JSON 解析（失败再按每行 `键: 值` 解析）；数值/布尔值转字符串。
- 非空规则无法归一化时拒绝写入并返回明确错误（工具描述与错误信息说明格式契约）；杜绝"写入 {} 却报成功"或只写入 tone/pov/tense 的部分成功。
- 读取侧（书籍风格面板 / 设定检查工具 / 内嵌阅读器风格页）与写入侧使用同一归一化：历史嵌套/数组形态数据可正常展平展示，并可原样回存为扁平形态（不做自动迁移）。
- 写作快照向 writer 渲染风格规则：快照工具输出与会话级系统注入的风格指南段在基调/视角/时态之外逐条渲染规则；快照预算改为"基调/视角/时态优先保留 + 规则逐条截断"，截断时提示完整规则可通过设定检查工具查询（现状是规则相关 token 超预算时整个风格指南被整体丢弃）。

## 非目标

- 不重设计「写作风格」UI 编辑器（保持"每行一条 键: 值"的扁平编辑），不引入树形/嵌套编辑。
- 不把 rules 存储形态改为嵌套 JSON——扁平字符串映射是唯一规范形态。
- 不改 tone/pov/tense 语义，不改 chapter_length / chapter_length_limit 的既有消费行为。
- 不做历史数据自动迁移（含《执棋人》已丢失规则的自动恢复）；不改协议与 SDK 生成物。
- 不改写作流水线的阶段结构，不新增审计维度。
- 不改造内部辅助消费点（连续性检查的规则计数、章节重建的观察者提示）中 rules 的读取形态——新写入形态（对象扁平映射）下两者行为不变。

## Capabilities

### New Capabilities

- `style-rules-pipeline`：风格规则的端到端契约——写入归一化（展平 + 拒绝静默失败）、读取侧同构归一化、写作快照渲染与预算截断，保证规则"存得下、看得见、用得上"。

### Modified Capabilities

（无——既有 setting-formatting / chapter-length-limit 的需求文本不变；规则归一化、失败语义与快照渲染由新能力的 requirements 覆盖。）

## Impact

- **packages/novel-store**：新增共享的规则归一化函数（单一事实源），供插件、服务端与内嵌阅读器等所有写读路径复用；风格指南写入边界（upsertStyleGuide、书籍元数据联合保存 saveBookMeta）统一走该归一化，并消除 saveBookMeta 现有的 JSON 双重编码写入。
- **packages/plugin**：save_novel_settings 的 style_guide 分支（归一化、拒绝假成功、工具描述）、状态提交管线的 style 分支（同一归一化）、设定检查工具的规则读取与展平展示、快照渲染（快照工具输出与会话级系统注入）、风格指南预算策略、architect/observer 提示词中的 rules 格式说明。
- **packages/server**：style_guide 读取归一化改用共享函数（含历史形态容错），HTTP 契约不变（rules 仍为字符串映射）。
- **packages/opennovel**：内嵌阅读器（`/reader` 风格页）的规则读取归一化——历史嵌套/数组/JSON 字符串形态数据显示为展平规则，不再出现 [object Object]。
- **packages/app / desktop**：无代码变更（面板显示随读取归一化自然改善）。**protocol/SDK**：无契约变更，无需再生成。
- **兼容性**：无表结构与数据模型变更；历史嵌套/数组形态数据的展示形态改为展平/索引编号（内容不丢失、可编辑回存）。《执棋人》当前已丢失的规则不自动恢复，可从会话日志人工回填（另行决定）。
