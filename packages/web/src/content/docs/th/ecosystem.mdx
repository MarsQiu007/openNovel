ชุดโครงการชุมชนที่สร้างขึ้นบน OpenNovel

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ OpenNovel ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-opennovel](https://github.com/awesome-opennovel/awesome-opennovel) และ [opennovel.cafe](https://opennovel.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
