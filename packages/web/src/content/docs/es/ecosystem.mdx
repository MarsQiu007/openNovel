Una colección de proyectos comunitarios construidos en OpenNovel.

:::note
¿Quieres agregar tu proyecto relacionado con OpenNovel a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-opennovel](https://github.com/awesome-opennovel/awesome-opennovel) y [opennovel.cafe](https://opennovel.cafe), una comunidad que agrega el ecosistema y la comunidad.
