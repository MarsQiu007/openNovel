Eine Sammlung von Community-Projekten, die auf OpenNovel basieren.

:::note
Möchten Sie Ihr OpenNovel-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-opennovel](https://github.com/awesome-opennovel/awesome-opennovel) und [opennovel.cafe](https://opennovel.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
